# Ahmad Bilto — Portfolio

The source for [ahmadbilto.com](https://ahmadbilto.com), Ahmad Bilto's interactive portfolio as a Unity gameplay and tools developer.

The site presents selected projects, editor tools, professional experience, and a downloadable resume through an explorable 3D campsite and journal interface. It also includes an embedded Unity WebGL showcase.

## Stack

- React 19
- TypeScript
- Vite
- Three.js and React Three Fiber
- Unity WebGL
- GitHub Pages

The Unity WebGL data package is distributed through a GitHub Release and assembled during deployment to stay within GitHub's repository file-size limit.
